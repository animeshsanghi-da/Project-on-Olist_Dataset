# Anaconda Environment Setup Guide
---
Here is a quick guide to set up the local environment for this project.

<br>

## 1. Create the Requirements File
---
In your project folder, create a text file named `requirements.txt`. Add the following core libraries:

```text
pandas
numpy
matplotlib
seaborn
scikit-learn
mysql-connector-python
SQLAlchemy
jupyter
python-dotenv
```

<br>

## 2. Create the Anaconda Environment
---
Open your terminal or command prompt. Run this command to create a new environment named `animesh_env` using Python 3.10:

```bash
conda create --name animesh_env python=3.10
```
Press 'y' and hit enter when it asks to proceed.

<br>

## 3. Activate the Environment
---
Once it is installed, activate the new environment:

```bash
conda activate animesh_env
```
You should now see `(animesh_env)` at the start of your terminal line.

Next, install the required libraries from your text file:

```bash
pip install -r requirements.txt
```

<br>

## 4. Link the Environment to Jupyter
---
If you use Jupyter Notebooks, you need to link this environment so Jupyter does not use your system's default Python. Run this inside your activated environment:

```bash
python -m ipykernel install --user --name=animesh_env --display-name="Python (Olist E-commerce Project by Animesh)"
```
When you open your Jupyter notebook, go to the top menu: Kernel > Change Kernel, and select "Python (Olist E-commerce Project by Animesh)". This makes sure your code runs properly.

<br>

## 5. Keeping it GitHub Ready
---
If you install any new libraries later, add their names to your `requirements.txt` file manually. Keeping this list simple makes it easy for hiring managers or other developers to run your project without errors.

Or, you can generate an exact list of everything in your environment by running:

```bash
conda list -e > requirements.txt
```
This overwrites your simple text file with a detailed list of exact version numbers, which is great for a professional portfolio.
